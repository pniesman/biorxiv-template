# biorxiv-template

Template made for bioRxiv preprints for typst. Modified from Robin Eklind's cellpress-unofficial template https://github.com/mewmew/cellpress-unofficial with inspiration from Christian L. Ebbesen's bioRxiv word template https://github.com/chrelli/bioRxiv-word-template. 

Still need to add custom figure handling possibly. 

Requires typst 0.14+
